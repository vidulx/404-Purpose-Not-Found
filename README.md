### Project Description

CURSOROLOGY is a completely unnecessary system that studies how a person moves their mouse cursor and pretends those movements reveal their personality, behavior, and decision-making.

It tracks cursor movement, clicks, pauses, direction changes, and movement patterns, then generates a completely serious-looking psychological report about something that absolutely does not need psychological analysis.

### The Problem (that doesn't exist)

People use their mouse every day without knowing what their cursor movements say about them.

Are they hesitant?  
Are they chaotic?  
Do they move their cursor with purpose?  
Do they have free will?

These completely unnecessary questions have remained unanswered for far too long.

### The Solution (that nobody asked for)

CURSOROLOGY tracks the user's cursor movement throughout the application and analyzes every unnecessary detail of it.

It measures:

- Cursor movement distance
- Movement speed
- Pauses
- Direction changes
- Reversals
- Clicks
- Movement patterns
- Exploration behavior
- Cursor density

The system then converts these meaningless measurements into highly questionable metrics such as:

- Purposefulness
- Hesitation Index
- Chaos Index
- Free Will Coefficient
- Path Efficiency
- Exploration Level
- Movement Complexity

Finally, it generates a completely unnecessary behavioral report explaining what the user's cursor supposedly reveals about them.
